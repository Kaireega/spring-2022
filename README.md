# spring-2022

Java data structures and algorithms practice (2022) — BSTs, linked lists, stacks, queues, inheritance, and OOP exercises.

---

## Categories

### Data structures
| File | Description |
|------|-------------|
| `BST.java`, `BST1.java` | Binary search trees |
| `SL.java`, `SList.java`, `SList2.java`, `DL.java` | Singly and doubly linked lists |
| `ArrayStack.java`, `ArrayQueue.java` | Stack and queue implementations |
| `DArray.java`, `ArrayItr.java` | Dynamic arrays and iterators |

### Object-oriented programming
| File | Description |
|------|-------------|
| `Animal.java`, `Bear.java`, `Fish.java`, `Ecosys.java` | Inheritance and ecosystems |
| `Empolyee.java`, `Student.java`, `PersonalInfo.java` | Employee/student hierarchies |
| `GenerBase.java`, `GenerInter.java` | Generics |

### Applications
| File | Description |
|------|-------------|
| `Amazon.java`, `Walmart.java`, `Sellable.java` | Store simulation |
| `TicTacToe.java` | Tic-tac-toe game |
| `SimpleCalculator.java` | Calculator |
| `Solution.java` | Algorithm solutions |

---

## Prerequisites

- JDK 8+

---

## How to run

```bash
git clone https://github.com/Kaireega/spring-2022.git
cd spring-2022

javac TicTacToe.java && java TicTacToe
javac BST.java && java BST
```

Each file is standalone — compile the file(s) you want to explore.
